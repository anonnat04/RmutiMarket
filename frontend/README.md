# CampusMarket — Frontend

เว็บซื้อขายสินค้าภายในมหาวิทยาลัยเทคโนโลยีราชมงคลอีสาน
สร้างด้วย **React + TypeScript + Vite + TailwindCSS + React Router + Zustand**

## สิ่งที่ทำเสร็จแล้ว

**หน้าเว็บ**
- **Home** (`/`) — banner + หมวดหมู่ยอดนิยม + สินค้าแนะนำ
- **สินค้าทั้งหมด** (`/products`) — ค้นหา + กรองตามหมวดหมู่
- **รายละเอียดสินค้า** (`/products/:id`) — รูป, ราคา, ผู้ขาย, ปุ่มแชท, ปุ่มบันทึกรายการโปรด
- **ลงขายสินค้า** (`/products/create`) 🔒 — ฟอร์มลงประกาศ พร้อมอัปโหลดรูป (ลากจัดลำดับ/เลือกรูปปก),
  ฟิลด์เพิ่มเติมตามหมวดหมู่ (เช่น ISBN สำหรับหนังสือ), บันทึกแล้วขึ้นแสดงในฟีดทันที
- **สินค้าของฉัน** (`/my-products`) 🔒 — แท็บ กำลังขาย / จองแล้ว / ขายแล้ว / แบบร่าง เปลี่ยนสถานะได้
- **รายการโปรดของฉัน** (`/wishlist`) 🔒 — สินค้าที่กดหัวใจไว้
- **แชท** (`/chat`) 🔒 — รายชื่อการสนทนา + ส่งข้อความ (mock ยังไม่ต่อ backend จริง)
- **โปรไฟล์** (`/profile`) 🔒 — ข้อมูลผู้ใช้ + ออกจากระบบ
- **นัดรับสินค้า** (`/products/:id/meetup` → `/meetups`) 🔒 — ระบบนัดรับสินค้าเต็มรูปแบบ เขียนเป็น **plain JavaScript (.js/.jsx)** ตามที่ขอ (ส่วนอื่นของโปรเจกต์ยังเป็น TypeScript ตามเดิม ใช้ร่วมกันได้เพราะเปิด `allowJs` ไว้แล้ว):
  - ผู้ซื้อกด "นัดรับสินค้า" ที่หน้าสินค้า → เลือกวันที่/เวลา/จุดนัดรับ (มีแผนที่ มทร.อีสาน จริงให้กดเลือกจุดบนแผนที่ หรือเลือกจากรายการก็ได้ — ใช้รูปที่ส่งมาเป็นพื้นหลัง)
  - ผู้ขายเห็นคำขอที่ `/meetups` แล้วเลือก ยืนยัน / ขอเลื่อนวัน-เวลา / ปฏิเสธ
  - ระบบเจรจาขอเลื่อนนัด (reschedule) ครบวงจร: เสนอวันใหม่ + เหตุผล → อีกฝ่าย ยอมรับ/เสนอวันใหม่/ปฏิเสธ วนได้จนกว่าจะตกลง
  - ถึงวันนัด ทั้งสองฝ่ายกดยืนยันส่งมอบแยกกัน ระบบจะปิดงานเป็น "ส่งมอบสำเร็จ" เมื่อยืนยันครบทั้งคู่
  - เปิดให้รีวิว + ให้คะแนนดาว หลังส่งมอบสำเร็จ
  - ทุกอย่างเก็บใน `meetupStore.js` (persist localStorage) — พอมี backend จริงค่อยเปลี่ยนไปเรียก API แทน

- หน้าที่ยังไม่ทำ (want-to-buy, ประวัติการซื้อขาย, แจ้งเตือนภัย, ตั้งค่า) จะขึ้นหน้า "กำลังพัฒนา" แทนการเงียบๆ เด้งกลับหน้าหลัก

🔒 = ต้องล็อกอินก่อนถึงเข้าได้ (คุมด้วย `PrivateRoute`, ถ้ายังไม่ล็อกอินจะเด้งไปหน้า login แล้วพากลับมาหน้าเดิมให้อัตโนมัติหลังล็อกอินสำเร็จ)

**ระบบเบื้องหลัง (mock, client-side)**
- `authStore` — เก็บสถานะล็อกอิน (persist ใน localStorage) ใช้แทน backend auth ชั่วคราว
- `myListingsStore` — เก็บประกาศที่ผู้ใช้ลงเอง แสดงรวมกับสินค้า mock ในทุกหน้า
- `cartWishlistStore` — เก็บรายการโปรด ใช้ร่วมกันทั้ง ProductCard และหน้า Wishlist
- Mock data (`src/data/mockProducts.ts`) ใช้แทน backend ผ่าน `src/services/productService.ts`
  (พอ backend พร้อม ให้แก้ไฟล์นี้ไฟล์เดียวไปเรียก `axiosClient` แทน โดยไม่ต้องแก้หน้าอื่น)

## วิธีรันโปรเจกต์

```bash
cd campusmarket-frontend
npm install
npm run dev
```

จะเปิดที่ `http://localhost:5173`

## บั๊กที่แก้ไปแล้ว

- `@import` ใน `tailwind.css` เคยอยู่หลัง `@tailwind` (ผิดตำแหน่งตามสเปก CSS) ทำให้ธีม gradient/การ์ด/badge
  ทั้งหมดใน `theme.css` ไม่ถูกโหลด — ย้ายไปไว้บรรทัดบนสุดแล้ว
- เพิ่มรูป placeholder (picsum.photos) ในสินค้าตัวอย่าง เพราะเดิมไม่มีรูปเลย

## โครงสร้างที่ยังไม่ได้ทำ (โมดูลถัดไป)

Transaction (auto-release เงิน), Returns,
Trust/Reviews แบบเต็ม, Report/Scam alert, Notification, Analytics, Admin

แนะนำให้ทำต่อทีละโมดูล โดยเพิ่ม route ใน `src/routes/AppRoutes.tsx`
และสร้าง service ใหม่ในโฟลเดอร์ `src/services/` ตามแพทเทิร์นเดียวกับ `productService.ts`

## หมายเหตุ

- สภาพแวดล้อมที่เขียนโค้ดนี้ไม่มีอินเทอร์เน็ตให้ดึงแพ็กเกจ npm ผมจึงตรวจโค้ดด้วยการเช็ค bracket/brace,
  เช็ค import ทุกไฟล์ว่าชี้ไปหาไฟล์จริง, และอ่านทวนทุกไฟล์ด้วยตัวเอง แต่ยังไม่ได้รัน `npm run dev` จริง
  แนะนำให้ลองรันแล้วแจ้งผลกลับมาได้เลยถ้าเจอ error
